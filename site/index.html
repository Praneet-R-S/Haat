Made by hand. Sold abroad. The rest is paperwork.

Haat is an export desk run by AI agents for India's weavers, block printers and potters. A maker sends a photo and a voice note in Hindi or Tamil. The agents write the listing, price it, take the payment through PayPal, do the export paperwork, ship it and pay every maker their share.

Then a buyer in Ohio pays. The desk keeps working.

The moment PayPal captures the payment, the seller's autopilot runs five steps. Every PayPal call it makes is written to the ledger as it happens, with PayPal's debug id beside it.

i.

Read what PayPal settled.

  • POST /v2/checkout/orders/{id}/capturethe capture itself
  • gross_amountwhat the buyer paid
  • paypal_feethe fee PayPal actually took
  • net_amountwhat reaches the seller
  • seller_protection.statuscovered, or not yet

No more estimates. The fee and the net, exactly as PayPal settled them.

ii.

Write the export invoice.

  • GST export invoiceunder LUT, so no IGST is charged
  • purpose code P0103RBI code for payment before shipment
  • HS 5208.52woven cotton fabric, printed

The papers a small exporter has to keep, written from the order itself.

iii.

Book the parcel. Tell PayPal.

  • India Post EMSthe booking is simulated in the sandbox
  • POST /v2/checkout/orders/{id}/tracktracking attached to the capture

Tracking on the capture is what keeps the sale under seller protection.

iv.

Pay every maker their share.

  • POST /v1/payments/payoutsone item per maker, from a marketplace account outside India
  • upi://payor, from an Indian account, one UPI request per maker

The cooperative's split. PayPal brings the dollars into India; each maker's share goes out by PayPal Payouts or, from an Indian account, by UPI.

v.

Tell him, in his own language.

  • message to the sellerin Hindi, like the voice note

He asked in Hindi, so he hears back in Hindi. A Tamil weaver hears back in Tamil.

And if a buyer disputes.

The dispute desk drafts the evidence.

  • POST /v1/customer/disputes/{id}/provide-evidencesend the case it prepared
  • POST /v1/customer/disputes/{id}/accept-claimor concede, if that is fair
  • POST /v1/notifications/verify-webhook-signatureno webhook is believed unchecked

It reads the claim and prepares the case. The seller decides which to send.

His next buyer might not be a person.

A shopper can hand the search to Haat's buyer agent with a spending mandate: a ceiling on the landed price and a country to ship to. The agent searches, checks the landed cost and prepares a real PayPal order. It cannot pay. The human approves in PayPal, or nothing happens.

Haat is also an MCP server, so outside agents such as Claude or ChatGPT can shop it with the same tools.
